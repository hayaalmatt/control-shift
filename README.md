# Control Shift

*A psychological survival game built with Java and JavaFX.*

## Overview

Control Shift is a 2D first-person psychological survival game developed as a team project for Object-Oriented Programming II (SE220) at Alfaisal University.

Set in an isolated office during a night shift, the game challenges players to monitor surveillance cameras and resolve system sabotages before a hostile robot takes control of the digital infrastructure. Players must complete tasks under time pressure, manage their remaining lives, and survive increasingly difficult challenges across three levels.

Beyond its survival mechanics, Control Shift incorporates cybersecurity awareness by presenting educational tips related to the sabotage scenarios players encounter.

## Gameplay

The game takes place during a simulated night shift from 12:00 AM to 9:00 AM. Each in-game hour lasts 30 seconds, requiring players to prioritize tasks and respond quickly to emerging threats.

The game features three progressive levels:

- **Level 1 — Server Overload:** Unlock surveillance cameras, solve a word puzzle, and repair a sabotaged digital clock.
- **Level 2 — System Sabotage:** Restore corrupted code, reconnect electrical wires, and recover disabled surveillance cameras.
- **Level 3 — Critical Failure:** Handle multiple simultaneous sabotages, including computer overheating, under increasing time pressure.

Players start each level with three lives. Failed or ignored tasks cause the robot to advance through the surveillance cameras, bringing the player closer to a game-over state.

## Features

- **User Authentication:** Account creation, login validation, and player-specific accounts.
- **Interactive Menus:** Homepage, game modes, demo instructions, scoreboard, and settings.
- **Progressive Levels:** Three levels with increasing difficulty and distinct sabotage mechanics.
- **Time-Based Gameplay:** In-game clock and timed challenges.
- **Life and Game State Management:** Track remaining lives, robot progression, level completion, and game-over conditions.
- **Interactive Puzzles:** Password challenges, word unscrambling, code restoration, wire matching, and surveillance debugging.
- **Audio and Visual Effects:** Background audio, alerts, and jumpscare effects.
- **Cybersecurity Awareness:** Educational tips displayed after successfully resolving sabotage tasks.
- **Progression System:** Unlock levels as the player advances through the game.

## Technologies Used

- **JavaFX** — Desktop application framework and interactive gameplay.

## Software Design

The application uses a modular JavaFX structure to separate interface layouts, interaction handling, and gameplay logic.

- **FXML layouts** define the interface structure.
- **JavaFX controllers** handle user interactions and application behavior.
- **CSS stylesheets** maintain a consistent visual theme.
- **Java classes** manage gameplay mechanics, level progression, timers, lives, and sabotage tasks.

The development process also incorporated software engineering practices such as requirements analysis, UML modeling, iterative development, and functional testing.
